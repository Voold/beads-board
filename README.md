# Beads Board

Локальная доска для просмотра задач [Beads](https://github.com/gastownhall/beads). Показывает проекты, эпики и подзадачи в колонках по статусу, группирует карточки по дате последнего обновления, включая завершённые задачи. Кнопки в карточке **копируют промпт** для агента в буфер обмена. Сама доска задачи не изменяет.

## Запуск

Нужны Python 3 и установленный Beads CLI (`bd`). У доски нет сторонних Python или JavaScript зависимостей.

1. Склонируйте репозиторий.
2. На macOS откройте `start.command` двойным щелчком. На других системах из каталога репозитория выполните `python3 server.py`.
3. Откроется локальный адрес, обычно `http://127.0.0.1:8765/`. Если браузер не открылся автоматически, возьмите адрес из вывода команды.

Для запуска без открытия браузера: `python3 server.py --no-browser`. Для другого порта: `python3 server.py --port 9000`. Сервер слушает только `127.0.0.1`; остановка — `Ctrl+C`.

Быстро посмотреть внешний вид можно, открыв `index.html` напрямую. В этом режиме отображаются **вымышленные демозадачи**. Для своих актуальных задач запускайте сервер.

## Где доска ищет задачи

По умолчанию используется `~/beads`. Для другого расположения задайте `BEADS_HOME`, например `BEADS_HOME=/path/to/beads python3 server.py`. Исполняемый файл Beads ищется как `bd` в `PATH`; его можно указать через `BD_BIN=/path/to/bd`.

Сервер просматривает `projects/*/project.conf` в `BEADS_HOME` и читает каждую базу командой `bd --readonly list --all --json --limit 0`. Если база недоступна, он пробует локальный `history/<project>/issues.jsonl` и показывает предупреждение о снимке. Данные перечитываются кнопкой «Обновить» и каждые 30 секунд, пока вкладка видима.

Если проекты не появились, проверьте наличие `project.conf`, доступность `bd` и вывод сервера в терминале. Доска не регистрирует проекты и не создаёт Beads-базы.

## Для агентов

Запускайте проект из каталога репозитория командой `python3 server.py --no-browser`, если браузер открывать не нужно. Проверяйте JSON по `http://127.0.0.1:8765/api/projects`; UI находится по `/`. Для чтения задач используйте только `bd --readonly`. Не добавляйте операции изменения задач или HTTP-методы записи: кнопки должны лишь копировать текст промпта.

`index.html` содержит только вымышленные демоданные. **Не коммитьте** реальные выгрузки Beads, снимки `issues.jsonl`, личные пути, токены или содержимое `~/beads`. При изменении интерфейса проверяйте режим демоданных (`file://`) и живой режим через локальный сервер. Для проверки Python-синтаксиса без создания файлов: `python3 -c "from pathlib import Path; compile(Path('server.py').read_text(), 'server.py', 'exec')"`.

Этот репозиторий — отдельный интерфейс к локальному Beads. Для работы с задачами в чужом проекте сначала прочитайте его `AGENTS.md` и используйте предусмотренный там CLI или обёртку.
