# Beads Board

Локальная доска для просмотра задач [Beads](https://github.com/gastownhall/beads). Вкладка «Доска» показывает проекты, эпики и подзадачи в колонках по статусу, группирует карточки по дате последнего обновления, включая завершённые задачи. «Дерево эпиков» показывает вложенность задач и блокирующие зависимости. «Граф задач» показывает **все задачи проекта** в отдельном поле: связанные задачи образуют группы, несвязанные группы лежат рядом. Кнопки в карточке **копируют промпт** для агента в буфер обмена. Сама доска задачи не изменяет.

Граф автоматически выстраивается **справа налево**: родительские и исходные задачи находятся справа, их подзадачи и зависимые задачи — на следующих уровнях слева. Ветви выравниваются, карточки не перекрываются; длинные связи проходят снаружи группы. Синие стрелки идут от родителя к подзадаче, жёлтые пунктирные — от блокера к зависимой задаче. Циклические связи сохраняются; участвующие задачи получают отметку «↻ цикл» и могут находиться на одном уровне. Карточка показывает название в две строки, тип, статус и приоритет. При наведении или фокусе выделяются непосредственные связи задачи.

Проекты переключаются вкладками. Перетаскивайте карточки и пустое поле мышью или пальцем; колёсико и кнопки `+`/`−` меняют масштаб, «Весь граф» возвращает общий вид, «Выровнять» заново строит автоматическую раскладку. При переносе задачи за ней движутся все её подзадачи, включая вложенные уровни. Родитель и соседние задачи при переносе подзадачи остаются на месте; блокирующие связи на движение не влияют. Поиск подсвечивает задачи, `Enter` переносит к первой найденной. Нажатие на задачу открывает подробности. Перестановка карточек хранится в открытой вкладке до перезагрузки страницы; при появлении новых задач или изменении связей раскладка строится заново.

## Запуск

Нужны Python 3 и установленный Beads CLI (`bd`). У доски нет сторонних Python или JavaScript зависимостей.

1. Склонируйте репозиторий.
2. На macOS откройте `start.command` двойным щелчком. На других системах из каталога репозитория выполните `python3 server.py`.
3. Откроется локальный адрес, обычно `http://127.0.0.1:8765/`. Если браузер не открылся автоматически, возьмите адрес из вывода команды.

Для запуска без открытия браузера: `python3 server.py --no-browser`. Для другого порта: `python3 server.py --port 9000`. Сервер слушает только `127.0.0.1`; остановка — `Ctrl+C`.

Быстро посмотреть внешний вид можно, открыв `index.html` напрямую. В этом режиме отображаются **вымышленные демозадачи**. Для своих актуальных задач запускайте сервер.

## Где доска ищет задачи

Папки проектов у всех разные. Доска использует три **явных** источника путей и показывает их вместе:

1. **Обычные проекты с `.beads` в репозитории.** Укажите корни проектов при запуске: `python3 server.py --project ~/work/app --project /path/to/another-app`. Можно также передать путь к самой папке `.beads`.
2. **Запуск двойным щелчком.** Скопируйте `projects.example.txt` в `projects.local.txt` и впишите по одному пути к проекту на строку. `start.command` подхватит список автоматически. Поддерживаются абсолютные пути, `~` и пути относительно папки доски. `projects.local.txt` игнорируется Git и не должен попадать в публичный репозиторий.
3. **Приватный реестр, если он у вас есть.** По умолчанию доска дополнительно проверяет `~/beads/projects/*/project.conf`. Если реестр находится в другом месте, задайте `BEADS_HOME=/path/to/beads`. Этот режим нужен только для установки, где проекты зарегистрированы в отдельном каталоге; для обычных `.beads` используйте `--project` или `projects.local.txt`.

Исполняемый файл Beads ищется как `bd` в `PATH`; его можно указать через `BD_BIN=/path/to/bd`. Доска не сканирует домашний каталог и не ищет проекты наугад. Каждый найденный проект читается командой `bd --readonly list --all --json --limit 0` из указанной папки. Для дерева и графа используются `parent` и связи `parent-child`; метка «Зависит от» и жёлтые стрелки обозначают связь `blocks` от блокера к зависимой задаче. Только для приватного реестра, если живая база недоступна, сервер пробует `history/<project>/issues.jsonl` и показывает предупреждение о снимке. Данные перечитываются кнопкой «Обновить» и каждые 30 секунд, пока вкладка видима.

Если проект не появился, проверьте путь, наличие `.beads`, доступность `bd` и вывод сервера в терминале. Доска не регистрирует проекты и не создаёт Beads-базы.

## Для агентов

Запускайте проект из каталога репозитория командой `python3 server.py --no-browser --project /path/to/project`, если браузер открывать не нужно. Для нескольких проектов повторите `--project` или заполните локальный список. Проверяйте JSON по `http://127.0.0.1:8765/api/projects`; UI находится по `/`. Для чтения задач используйте только `bd --readonly`. Не добавляйте операции изменения задач или HTTP-методы записи: кнопки должны лишь копировать текст промпта.

`index.html` содержит только вымышленные демоданные. **Не коммитьте** `projects.local.txt`, реальные выгрузки Beads, снимки `issues.jsonl`, личные пути, токены или содержимое `~/beads`. При изменении интерфейса проверяйте режим демоданных (`file://`) и живой режим через локальный сервер. Для проверки Python-синтаксиса без создания файлов: `python3 -c "from pathlib import Path; compile(Path('server.py').read_text(), 'server.py', 'exec')"`.

Этот репозиторий — отдельный интерфейс к локальному Beads. Для работы с задачами в чужом проекте сначала прочитайте его `AGENTS.md` и используйте предусмотренный там CLI или обёртку.

Проверка раскладки, направлений связей, отсутствия перекрытий и состава переносимых подзадач: `node --test tests/graph.test.cjs`. Node.js нужен только для этих проверок, не для работы доски; установка пакетов не требуется.

Проверка чтения UTF-8 вывода Beads и обработки ошибок: `python3 -B -m unittest discover -s tests -p 'test_*.py' -v`.
